# Memo Maker

Memo Maker транскрибирует записи встреч на своём компьютере и по желанию сразу делает по ним мемо через Claude Code, а потом сжимает запись, чтобы она занимала меньше места. Приложение живёт в трее Windows и следит за папкой, куда OBS пишет записи. Когда запись закончена, оно спрашивает, обрабатывать ли её, под каким именем и куда сохранить результат, и ставит встречу в очередь. Звук распознаётся моделью Whisper large-v3 на видеокарте и никуда не отправляется.

## 1. Возможности

1. Слежение за папкой с записями и окно с вопросом после окончания записи. Название подставляется с датой записи, папка для результата выбирается из списка и запоминается.
2. Очередь встреч с порядком, повтором и отменой. Два режима нагрузки: "Быстро" занимает видеокарту полностью, "Щадяще" работает дольше и оставляет видеокарту свободнее.
3. Транскрипция текстом с метками времени, абзацами и пунктуацией.
4. Мемо через Claude Code в режиме командной строки. Если в папке "Проект для мемо" есть скилл meeting-memo, Claude работает по нему, иначе пишет мемо в Markdown.
5. Сжатие записи в H.265 на видеокарте, подробнее в разделе 2.
6. Журнал хода работы с ключевыми этапами, ответом Claude и итогом: время, токены, стоимость по прайсу, размер видео до и после сжатия.
7. Уведомления Windows о готовой транскрипции, мемо и сжатии, оформление в светлой или тёмной теме Windows.

## 2. Сжатие видео

Переключатель "Сжать видео в H.265 после транскрибации" в окне новой записи. Сжатый файл `<имя записи> (H.265).mp4` кладётся рядом с записью, даты у него как у записи. Запись созвона из OBS ужимается примерно до 10 % размера, на глаз как оригинал: настройки те же, что у сжатия в Arch Clean Maker (hevc_nvenc, CQ 23). Часовая встреча сжимается на GTX 1660 Ti примерно за 13 минут.

1. Сжатие идёт после транскрибации и мемо. Whisper слушает только звук, а звук при сжатии копируется без изменений, поэтому текст от порядка не зависит. Зато транскрипция и мемо приходят без задержки.
2. Видеокарту сжатие уступает. Пока OBS пишет новую запись или открыто окно новой записи, оно ждёт. Встречи, которым нужна транскрибация или мемо, идут вперёд. Если такое случилось посреди сжатия, ffmpeg останавливается, а потом сжатие начинается заново. Запись Memo Maker замечает, только когда включено слежение за папкой.
3. Оригинал по умолчанию остаётся. С флажком "Удалить оригинал после проверки сжатого" он удаляется безвозвратно, мимо корзины, но только после проверки: сжатый файл в H.265, длительность совпадает, файл декодируется целиком без ошибок.
4. Не сжимаются видео, которые уже в H.265, AV1 или VP9, и аудиофайлы. Если сжатый файл меньше оригинала не на четверть, он удаляется и остаётся оригинал.
5. Если сжатие не удалось или его прервали, "Повторить" запускает только сжатие. Если оригинал удалён, а транскрипцию нужно сделать заново, она делается по сжатому файлу.

## 3. Требования

1. Windows 10 или 11.
2. Видеокарта NVIDIA с 4 ГБ видеопамяти или больше. Без неё распознавание возможно только на процессоре, это в несколько раз медленнее.
3. Python 3.12 и пакеты из `requirements.txt`. Процесс транскрибации держит в оперативной памяти 3-4 ГБ.
4. Модель Whisper large-v3, около 3 ГБ. Сначала она ищется в общей папке `C:\ProgramData\MemoMaker\models`, которую читают все пользователи компьютера. Если там её нет, она скачивается сама при первой транскрибации в кэш Hugging Face текущего пользователя.
5. Для мемо: Claude Code, установленный и авторизованный у текущего пользователя (`claude`, затем `/login`).
6. Для сжатия: ffmpeg с кодировщиком hevc_nvenc, папка с `ffmpeg.exe` и `ffprobe.exe` в системной переменной PATH, чтобы его видели все пользователи. Сейчас это `C:\ffmpeg\bin`.

## 4. Установка

```
py -3.12 -m pip install -r requirements.txt
powershell -ExecutionPolicy Bypass -File install.ps1
```

Скрипт `install.ps1` создаёт ярлыки Memo Maker на рабочем столе, в меню "Пуск" и в автозагрузке текущего пользователя. Ярлыкам присваивается идентификатор приложения, поэтому на панели задач показывается иконка Memo Maker, а не Python. Автозапуск потом включается и выключается переключателем в окне приложения.

## 5. Установка для другого пользователя Windows

Пакеты Python, установленные в общую папку Python, и модель в `C:\ProgramData\MemoMaker\models` доступны всем пользователям. Остальное у каждого пользователя своё. Копия приложения для других пользователей лежит в `C:\ProgramData\MemoMaker`, профиль другого пользователя по умолчанию закрыт. Под учётной записью этого пользователя нужно:

1. Запустить установку ярлыков и автозапуска:
   ```
   powershell -ExecutionPolicy Bypass -File C:\ProgramData\MemoMaker\install.ps1
   ```
2. Для мемо установить Claude Code и выполнить `/login`, затем выбрать в окне "Проект для мемо".
3. Выбрать в окне папку наблюдения и папки для результатов.

Копия в `C:\ProgramData\MemoMaker` обновляется копированием файлов из этого репозитория, ярлыки при этом пересоздавать не нужно.

## 6. Файлы

1. `memo_maker.pyw`: приложение в трее.
2. `transcribe.py`: транскрибация, работает и отдельно из командной строки, `py -3.12 transcribe.py --help`.
3. `install.ps1`: ярлыки и автозапуск.

Настройки, список папок и очередь хранятся в `%APPDATA%\MeetingTranscriber\settings.json`.
